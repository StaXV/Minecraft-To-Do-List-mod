# To-Do List — Minecraft 26.2 Fabric Mod

作者：StaXV　|　许可证：MIT

一个纯客户端 Fabric 模组，让你在 Minecraft 里随时记录并查看待办事项，不用切出游戏。

## 1. 项目解决什么问题

玩生存/整合包时，经常会冒出“马上要做的事”——挖矿路线、要去的地点、要合成的材料、要拿的装备，很容易玩着玩着就忘。平时只能用聊天栏、画板或切出游戏记，既不直观也容易丢。

这个模组把一本**原版书风格的待办清单**做进游戏里：按 **M** 键一秒打开，把要做的事写下来；也能把一个**迷你待办悬浮窗**固定到游戏界面任意角落，随时能看到还剩哪些没做。所有内容自动存到本地 JSON，重启游戏、换存档都不丢。

核心价值：**在游戏内随手记、随时查、完成后打勾、自动保存**，不打断游戏节奏。

## 2. 主要功能

- **一键开关**：默认按 **M** 键打开 / 关闭待办书（可在 选项 → 按键设置 → 待办 中改键）。
- **新建 / 编辑 / 删除**：每条待办有标题 + 多行内容；编辑页用原版多行输入框。
- **完成标记**：点击待办前的原版方框标记完成 / 取消完成；**完成后仍留在原位置**，待办按创建顺序固定排列，不会自动挪到最前或最后。
- **原版书式分页**：主界面是一本摊开的书（原版 `book.png` 背景），每页最多 **5 条**，用原版翻页按钮（左下 / 右下）；**首页只能向后翻、末页只能向前翻**，带原版翻页音效。
- **迷你待办悬浮窗**：在游戏界面显示一个小型待办清单（原版圆角 toast 背景），可：
  - 通过「位置设置」（以实时游戏为背景）直接**拖动到任意位置**，且不会超出屏幕边缘（四周留 4 像素）
  - 调整**宽度**（100–320 像素）
  - 调整**最多显示条数**（1–5 条，默认 5）
  - 只显示**未完成**或全部
  - 调整**透明度**（0–100，默认 100；0 时完全隐藏）
- **自动保存**：待办存到 `config/memo.json`，设置存到 `config/memo_settings.json`（都在游戏目录的 `config/` 下）。
- **全原版 GUI**：书页背景、复选框、按钮、翻页按钮、输入框均为原版素材，观感统一。
- **中英文双语**：跟随游戏语言切换。
- **可选 Mod Menu 入口**：装了 Mod Menu 后，可从模组列表直接打开设置页。

## 3. 安装方法

### 环境要求

- Minecraft **26.2**（Java Edition）
- Fabric Loader **0.19.3+**
- Fabric API **0.158.0+**（`fabric-api-0.158.0+26.2`）
- Java **25**
- （可选）Mod Menu **20.0.x**，用于从模组管理界面打开设置

### 步骤

1. 用 [Fabric 安装器](https://fabricmc.net/use/) 给 26.2 安装 Fabric Loader（最新稳定 0.19.3）。
2. 把 `build/libs/To-Do list-1.0.0.jar` 放进 `.minecraft/mods/`。
3. 把 Fabric API（`fabric-api-0.158.0+26.2.jar`）也放进 `mods/`。
4. （可选）把 Mod Menu 20.0.x 放进 `mods/`，可在模组列表里打开设置。
5. 启动游戏，进存档后按 **M** 即可。

## 4. 使用方法

### 主界面（待办书）

- **M**：打开 / 关闭待办书。
- **左键点方框**：标记完成 / 取消完成。
- **左键点文字**：进入编辑。
- **右键点某一条**：删除（第一次显示“确认删除”，再点一次才删，防误触）。
- **翻页按钮**：书本左下 / 右下，向前 / 向后翻页。
- 底部按钮（等距对称）：
  - **＋**：新建待办
  - **设置**：打开设置页
  - **清空全部**：删除所有（需点两次确认）

### 编辑页

- 顶部输入标题（可选），下面多行输入内容。
- **保存 / 取消**，或按 **ESC** 返回；标题和内容都为空时不会保存空条目。

### 设置页

- **外观**：最多显示条数（1–5）、宽度（100–320 像素）、透明度（0–100）。
- **内容**：启用迷你待办、迷你待办只显示未完成。
- **位置**：「位置设置…」进入以实时游戏为背景的界面，拖动迷你待办到想要的位置；**确定**保存 / **取消**撤销；也可 **重置位置**。

## 5. 输入输出示例

下面用“你做了什么（输入） → 发生了什么（输出）”说明，并给出真实的数据格式。

### 示例 1：新建一条待办

- 输入：按 **M** 打开 → 点 **＋** → 标题写“去末地”，内容写“带满末影珍珠 / 备好金苹果” → 点 **保存**。
- 输出：回到待办书，出现该条目；`config/memo.json` 新增一条记录：

```json
[
  {
    "id": "b7e9a1c2-4f3d-5e6a-9c8b-0d1e2f3a4b5c",
    "title": "去末地",
    "content": "带满末影珍珠\n备好金苹果",
    "done": false,
    "createdAt": 1770000000000,
    "updatedAt": 1770000000000
  }
]
```

### 示例 2：完成一条待办

- 输入：在书里 **左键点** 前面的方框。
- 输出：方框变成完成态（带对勾），文字变淡并加删除线；该条**保持在原位置**；`memo.json` 中对应项变为 `"done": true`（`createdAt` 不变，所以位置不变）。

### 示例 3：开启并设置迷你待办悬浮窗

- 输入：进 **设置** → 勾选“启用迷你待办” → 把“最多显示条数”调到 5、“透明度”调到 80 → 点“位置设置…”把它拖到右上角 → 点“确定”。
- 输出：游戏界面上出现一个半透明小待办窗口；`config/memo_settings.json` 变化如下：

```json
{
  "pinnedEnabled": true,
  "pinnedOnlyUndone": true,
  "pinnedMaxEntries": 5,
  "pinnedWidth": 180,
  "pinnedX": 3,
  "pinnedY": 3,
  "pinnedOpacity": 80
}
```

> 说明：上面的 `id`、时间戳是示例值。数据文件位于 `<游戏目录>/config/`（例如 `.minecraft/config/memo.json` 与 `memo_settings.json`），可手动备份或编辑；重启游戏不会丢失。

## 开发

```bash
# 需要 Java 25（请替换成你机器上 Java 25 的路径）
set JAVA_HOME=<你的Java25路径>
gradlew.bat build
```

构建产物在 `build/libs/To-Do list-1.0.0.jar`。项目结构：

```
src/main/java        入口与通用代码
src/client/java      客户端界面、数据存储、迷你待办 HUD
src/client/resources 图标、GUI 素材
src/main/resources   fabric.mod.json 与中英文语言文件
tools/               资源生成脚本（Python + Pillow）
```
